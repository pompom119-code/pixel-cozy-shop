# 像素小店物語 (Pixel Cozy Shop)

一款結合 **16-Bit 復古像素經營養成** 與 **《煮過頭》(Overcooked!) 式實境廚房跑位烹飪** 的網頁遊戲。玩家將親自操控像素主廚穿梭於廚房與客席之間，體驗從「拿取生食材、切菜備料、下鍋控火防燒焦、拿盤盛裝上菜，到回收髒盤洗碗」的完整手作料理過程，同時自由改裝廚房動線、研發傳說隱藏食譜，並傾聽每位熟客的溫馨故事。

## 遊戲核心特色

- **實境五步手作料理**：告別單純數值等待，玩家需親自走位完成「拿原料 → 切菜揉製 → 入鍋組合烹煮 → 餐盤盛裝 → 上菜收盤洗碗」的完整節奏挑戰。
- **經典防燒焦機制**：料理煮熟後若未及時拿乾淨餐盤盛出，防燒焦警示條將開始倒數並響起警示音；一旦煮過頭燒焦，就必須空手清鍋丟入廚餘桶！
- **雙重直覺操控支援**：同時支援鍵盤街機操作（`WASD` + `Space` + `F`）與滑鼠／觸控智慧尋路（直接點擊任意食材箱或工作站，主廚會自動繞過障礙物走過去互動）。
- **廚房動線自由改裝與擴建**：可在「裝潢動線」模式購買並自由擺放橡木切菜台、流理暫放台、防焦銅爐、餐盤架與客席餐桌，並將店面從 `10×7` 擴建至 `12×8`、`14×9` 旗艦規模。
- **雙軌食譜研發系統**：除了在「食譜研發」投入儲藏室食材合成新菜單，營業時若直接在湯鍋裡放入正確的未知配方組合，也能**當場實戰領悟並解鎖隱藏食譜**！
- **純手動挑戰與二廚助手自由切換**：招募二廚與外場助手後可幫忙自動切好備料台上的生食材、減緩爐火燒焦速度並自動收桌洗碗；想挑戰極限手速時也可隨時一鍵切換為「純手動挑戰模式」。
- **熟客好感圖鑑與溫馨劇場**：每間分店皆有 6 位特色熟客，招待他們品嚐最愛料理可快速提升好感等級，解鎖三段專屬對話故事、稀有食材謝禮與紀念信物。
- **復古 8-Bit 晶片音效**：內建以瀏覽器 Web Audio API 即時合成的切菜、下鍋、收銀、燒焦警示與解鎖號角音效，無需額外音訊檔案即可隨開即玩。

## 廚房實境烹飪流程與操作說明

### 1. 控制按鍵一覽

| 操作項目 | 鍵盤快捷鍵 | 滑鼠 ／ 觸控螢幕操作 |
| :--- | :--- | :--- |
| **移動主廚** | `W` `A` `S` `D` 或 `↑` `↓` `←` `→` | 點擊地板格或使用畫面下方虛擬方向鍵 |
| **拿取 ／ 放下 ／ 盛盤 ／ 上菜** | `Space`（空白鍵）或 `E` | 直接點擊目標食材箱、工作站、餐桌，或點擊「拿取 / 放下 / 上菜」按鈕 |
| **切菜備料 ／ 清洗髒盤** | `F` 或 `C` | 空手狀態下直接點擊切菜台／洗碗槽，或點擊「切菜備料 / 洗碗」按鈕 |

> 主廚面向的前方一格會顯示**黃色虛線準星框**，代表按下 `Space` 或 `F` 時會互動的目標格。

### 2. 五步出餐標準流程

1. **查看上方點單票券**：客人入座後，畫面頂端票券列會顯示客人想吃的料理名稱、**所需食材組合圖示**（例如：`小麥粉 + 奶油`）以及耐心倒數條。
2. **拿取生鮮食材**：走到廚房最上排（第 1 排）對應的 **食材補給箱**，按 `Space` 或點擊拿取生鮮原料（若拿錯可對同一個箱子再按一次放回）。
3. **切菜揉製備料**：將生鮮原料放到 **「橡木切菜備料台」**，連按 `F`（或空手點擊）直到藍色進度條滿格，食材右上角出現綠色完成標記後即可拿起。
4. **投入爐鍋烹煮與盛裝**：
   - 將所有需要的**已備料食材**依序投入同一口 **「烹飪爐鍋」**（每口鍋最多可放 3 種食材，鍋底會顯示目前放入的食材小圖示）。
   - 橘色烹煮條滿格後會顯示綠色 **「煮熟」** 標記，此時請在防燒焦條歸零前，從 **「潔白瓷盤收納架」** 拿取一個乾淨餐盤對著爐鍋按 `Space` 盛裝完成！
5. **端菜上桌與洗碗循環**：
   - 端著盛好的料理走到點該道菜的客人餐桌旁按 `Space` 上菜，剩餘耐心越高可獲得額外 **早鳥小費（x1.3）** 與 **上菜連擊加成**！
   - 客人用餐完畢離開後會在桌上留下 **髒盤子**，請空手收走髒盤放入 **「不鏽鋼像素洗碗槽」**，按 `F` 洗淨後乾淨餐盤會自動補回盤架，同時讓餐桌恢復整潔迎接下一位客人。

## 系統環境需求

在本機電腦安裝與執行本專案前，請確認已安裝以下環境：

- **Node.js**：建議 `v20.0.0` 或以上版本（LTS）
- **套件管理工具**：`npm`（隨附於 Node.js）或 `bun`
- **現代網頁瀏覽器**：Chrome、Edge、Firefox 或 Safari 最新穩定版（支援 ES2022、SVG 與 Web Audio API）

可透過終端機輸入以下指令確認版本：

```bash
node -v
npm -v
```

## 安裝與啟動教學

### 步驟 1：下載或複製專案原始碼

將專案下載解壓縮，或透過 Git 複製至本機後進入專案資料夾：

```bash
git clone <你的專案儲存庫網址>
cd <專案資料夾名稱>
```

### 步驟 2：安裝專案相依套件

在專案根目錄執行以下指令安裝所有前端與開發套件：

```bash
npm install
```

### 步驟 3：啟動本機開發伺服器

安裝完成後，啟動 Vite 開發伺服器：

```bash
npm run dev
```

終端機顯示啟動成功後，打開瀏覽器前往：

```text
http://localhost:3000
```

即可立即開始遊玩！

### 步驟 4：建置正式版靜態檔案（選用）

若需要部署至靜態網站空間（如 GitHub Pages、Vercel、Netlify、Cloudflare Pages 等），可執行打包指令：

```bash
npm run build
```

打包完成的靜態檔案會輸出於 `dist/` 資料夾內，亦可透過以下指令在本機預覽打包結果：

```bash
npm run preview
```

## 常見問題排解 (FAQ)

### Q1：爐鍋不小心「煮過頭燒焦了」該怎麼辦？
請先將手上的東西放在空白的「流理暫放裝盤台」上，保持**雙手空空**走到燒焦的爐鍋前按 `Space` 清出焦黑食物，再走到「廚房分類廚餘桶」按 `Space` 丟棄即可恢復乾淨爐鍋。

### Q2：拿著餐盤盛錯料理或組合錯食材怎麼辦？
端著裝有失敗料理的餐盤走到「廚房分類廚餘桶」互動，系統只會**倒掉盤中廚餘並保留你手上的乾淨餐盤**，不會浪費盤子！

### Q3：為什麼沒有新客人進店入座？
請檢查客席餐桌上是否留有上一位客人吃完的**髒盤子**！餐桌必須收走髒盤恢復乾淨後，新客人才會入座；若乾淨餐盤用完，也請記得去洗碗槽清洗髒盤。

### Q4：改裝廚房時不小心擋住通路怎麼辦？
隨時切換到頂端導覽列的 **「裝潢動線」** 分頁，點選右上角 **「切換拆除回收」** 即可移除擋路的家具或工作站（退還 80% 金幣），重新規劃最順手的黃金跑位動線。

### Q5：遊戲進度存在哪裡？換瀏覽器會在嗎？
遊戲採用瀏覽器本機 `localStorage` 即時自動存檔（鍵名為 `pixel_cozy_shop_overcooked_v2`），重新整理網頁或關閉分頁皆不會遺失進度。若清除瀏覽器網站資料或更換不同裝置／無痕視窗，存檔將會重新開始。

## 技術架構

- **前端框架**：React 19 + TypeScript
- **建置工具**：Vite 8
- **樣式系統**：Tailwind CSS v4（搭配像素字體 `DotGothic16` 與等寬數值字體 `JetBrains Mono`）
- **畫面渲染**：原生可縮放 Crisp-Edges SVG 像素格地圖與 16×16 手繪像素圖元組件
- **音效引擎**：原生 Web Audio API 零外部依賴 8-Bit 晶片合成器
